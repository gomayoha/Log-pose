# Log Pose

Yohan's personal web app: every site, guide, Pinterest board, card and case file in one place, in seven islands.

**Open it:** https://gomayoha.github.io/log-pose/

On iPhone, open the link in Safari, tap **Share**, then **Add to Home Screen**. It opens full screen with its own icon and keeps working offline.

## The islands

| Island | What's on it |
| --- | --- |
| Workshop | Idea L Pack: the Building 05 Layout R6 floor plan (animated, all 21 sheets), monthly review, carton tracking, portal, guides, Claude sessions, Drive |
| Grand Line | Grand Archive, One Piece story and trivia, watch wall, 27 character folders, the crew's bounties, watch log |
| Boards | The five Pinterest boards |
| Card Vault | All 86 One Piece cards, and the four special editions from the Card Lab |
| Rabbit Hole | The 25 case files from the Rabbit Hole Archive |
| Sanctuary | Behold, the Scarlet Thread, Shehansa's A Levels |
| Captain's Log | Profile, bounty, documents, goals, your own links, toolbox |

The Log Pose button (the compass, or ⌘K on a Mac) points to where you should go now and searches everything. Goals and links you add are saved in the browser on each device.

## Files

- `index.html` – the app (data is built in)
- `img/` – pictures, resized and stripped of photo metadata
- `floor-plan/` – Building 05 · Layout R6
- `manifest.webmanifest`, `sw.js` – home-screen app and offline cache
- `builder/` – the scripts and page source the app is built from (they read the Grand Archive and Mysteries repos next to this one)
